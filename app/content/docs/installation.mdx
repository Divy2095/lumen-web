# Installation and configuration

Inspect and configure the selected backend revision without assuming that a clean checkout can run.

<Callout title="Onboarding is blocked at this baseline">The committed code imports a local storage-service module that is absent from the commit. The commands below describe repository preparation, not a verified complete installation. Read the known issues before starting services.</Callout>

## Inspect the revision

In your own development checkout, obtain the backend and select the documented revision if it is available there. Remote availability of the exact local commit was not tested by this website task.

```bash
git clone https://github.com/Divy2095/Lumen.git
cd Lumen
git checkout 4899210e659864a2026b13b7d3c558e92da08780
npm ci
cp .env.example .env
```

Stop before treating this as runnable: verify that the storage dependency is included in a supported revision. This documentation does not provide a replacement module or a command to bypass the missing dependency. See [known limitations](/docs/project/known-limitations/).

## Prepare the environment

Edit `.env` yourself. Use the same newly chosen local password for Compose's `POSTGRES_PASSWORD` and the application's `PGPASSWORD`. Never copy a real credential from source comments, screenshots or tests.

```bash
POSTGRES_DB=lumen
POSTGRES_USER=lumen
POSTGRES_PASSWORD=<choose-a-local-password>
PGHOST=127.0.0.1
PGPORT=5432
PGDATABASE=lumen
PGUSER=lumen
PGPASSWORD=<same-local-password>
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=
```

Angle-bracket values are editing placeholders, not executable shell syntax. The existing npm scripts load `.env` using Node's env-file option. Configuration names/defaults below come from source, not a claim that arbitrary values have been tested.

The supplied Redis container has no password configuration. Setting only the application `REDIS_PASSWORD` would not configure that container; keep service and client settings aligned. Continue to [infrastructure and migrations](/docs/getting-started/infrastructure/) only after the missing prerequisite is resolved in a supported backend revision.
